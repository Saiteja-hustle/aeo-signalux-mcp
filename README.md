# aeo-signalux-mcp

MCP server exposing 3 tools over my CursorClip AEO tracking sheet (AI-Overview tracking for screen recorder keywords).

## Tools
- `get_keyword(name)` — full task list for one keyword, with done/pending status
- `get_overall()` — ranking, search volume, competitor-names-instead across all keywords
- `get_priority_tasks()` — every unfinished P1 task across all keywords

## Run locally
python mcp_server.py
